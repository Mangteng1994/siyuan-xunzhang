# 寻章

轻量定位与批量整理插件。

寻章只保留几个高频动作：定位当前打开文档、按标记批量删除、批量移动、批量复制连续内容块。

想法来自 [IAliceBobI/sy-tomato-plugin](https://github.com/IAliceBobI/sy-tomato-plugin)，感谢 IAliceBobI。

## 功能

- `Alt+Enter`：在文档树中突出定位当前打开文档
- `Alt+Shift+;`：删除开始标记和结束标记之间的连续内容块
- `Alt+Shift+'`：移动开始标记和结束标记之间的连续内容块到目标标记处
- `Alt+Shift+Q`：复制开始标记和结束标记之间的连续内容块到目标标记处
- 右键顶部栏寻章图标：打开定位、插入标记、备用撤销、批量整理菜单

## 标记

推荐使用中文标记：

- `批量开始`
- `批量结束`
- `批量目标`

同时兼容旧标记：

- `aacc1`
- `aacc2`
- `aacc3`

## 用法

删除一段连续内容：

1. 在要处理的第一个内容块前新建空行，将光标放入空行，右键顶部栏寻章图标，选择“插入开始标记”。
2. 在要处理的最后一个内容块后新建空行，将光标放入空行，选择“插入结束标记”。
3. 执行“删除：批量开始 到 批量结束”，或按 `Alt+Shift+;`。

移动或复制一段连续内容：

1. 按上面的方式插入 `批量开始` 和 `批量结束`。
2. 在目标位置新建空行，将光标放入空行，选择“插入目标标记”。
3. 执行“移动：开始-结束 到 批量目标”，或按 `Alt+Shift+'`。
4. 执行“复制：开始-结束 到 批量目标”，或按 `Alt+Shift+Q`。

操作完成后，标记行会被清除。

## 撤销

寻章维护最近 5 次插件操作的备用撤销栈。执行插入标记、批量删除、批量移动、批量复制后，可通过右键顶部栏寻章图标，选择“撤销上一次批量操作”进行撤销。

`Ctrl+Z` / `Cmd+Z` 不由寻章接管，仍由思源原生编辑器处理。

注意：撤销栈只记录插件加载期间的新批量操作。插件重载、思源重启或旧版本已执行的操作，不能自动补进撤销栈。

## 更新记录

### v0.3.5

- 支持跨文档批量移动、批量复制：开始/结束标记留在源文档，目标标记可放在另一文档。
- 优先使用通过寻章最近一次插入的开始、结束、目标标记，降低历史旧标记误匹配风险。
- 优化刚新建空行后的标记插入识别：优先读取当前 DOM 块，并在思源块状态同步期间做短暂重试。
- 插入标记后不再等待 `flushTransaction` 阻塞返回，连续右键顶部栏菜单更稳定。

### v0.3.4

- 插件撤销严格改为寻章自身的右键菜单撤销栈。
- 移除 `v0.3.3` 中不可靠的思源原生 `protyle.undo` 接入。
- `Ctrl+Z` / `Cmd+Z` 继续完全交给思源处理。
- 重新打包 `package.zip`，用于集市识别新版本更新。

### v0.3.3

- `Ctrl+Z` / `Cmd+Z` 完全交给思源处理，寻章不再全局接管编辑器撤销快捷键。
- 插入标记、批量删除、批量移动、批量复制统一进入寻章插件级撤销栈，顶部栏右键菜单“撤销上一次批量操作”是唯一的寻章撤销入口。
- 批量操作只处理当前打开文档内的标记，避免把 A 文档操作挂到 B 文档撤销栈。
- 插入开始、结束、目标标记时，只更新当前光标所在空段落，不再自动在当前块上方或下方新增段落。
- 在非空段落插入标记时不覆盖原内容，只提示先新建空行。
- 修复插入标记使用异常事务 update 导致的块结构异常、右键菜单失效问题，改用思源块更新接口并登记合法 DOM 撤销数据。
- 删除右键菜单中的标记帮助项，但继续兼容旧标记 `aacc1`、`aacc2`、`aacc3`。

## 建议

- 批量操作前先确认开始、结束、目标标记在同一逻辑范围内
- 移动和复制需要 `批量目标`，删除不需要
- 如果快捷键难记，直接使用顶部栏图标右键菜单
