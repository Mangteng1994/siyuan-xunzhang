# 寻章

轻量定位与批量整理插件。

寻章只保留几个高频动作：定位当前打开文档、按标记批量删除、批量移动、批量复制连续内容块。

想法来自 [IAliceBobI/sy-tomato-plugin](https://github.com/IAliceBobI/sy-tomato-plugin)，感谢 IAliceBobI。

## 功能

- `Alt+Enter`：在文档树中突出定位当前打开文档
- `Alt+Shift+;`：删除开始标记和结束标记之间的连续内容块
- `Alt+Shift+'`：移动开始标记和结束标记之间的连续内容块到目标标记处
- `Alt+Shift+Q`：复制开始标记和结束标记之间的连续内容块到目标标记处
- 右键顶部栏寻章图标：打开定位、插入标记、备用撤销、批量整理菜单

## 标记

推荐使用中文标记：

- `批量开始`
- `批量结束`
- `批量目标`

同时兼容旧标记：

- `aacc1`
- `aacc2`
- `aacc3`

## 用法

删除一段连续内容：

1. 在要处理的第一个内容块前新建空行，将光标放入空行，右键顶部栏寻章图标，选择“插入开始标记”。
2. 在要处理的最后一个内容块后新建空行，将光标放入空行，选择“插入结束标记”。
3. 执行“删除：批量开始 到 批量结束”，或按 `Alt+Shift+;`。

移动或复制一段连续内容：

1. 按上面的方式插入 `批量开始` 和 `批量结束`。
2. 在目标位置新建空行，将光标放入空行，选择“插入目标标记”。
3. 执行“移动：开始-结束 到 批量目标”，或按 `Alt+Shift+'`。
4. 执行“复制：开始-结束 到 批量目标”，或按 `Alt+Shift+Q`。

操作完成后，标记行会被清除。

## 撤销

批量删除、移动、复制和插入标记会尽量进入思源当前文档的原生撤销栈。

- 在执行操作的文档中按 `Ctrl+Z`，遵循思源原生撤销顺序
- 找不到当前编辑器时，寻章才记录最近 5 次批量操作到备用撤销栈
- 右键顶部栏寻章图标，选择“撤销上一次批量操作”，可显式使用备用撤销栈

注意：备用撤销栈只记录插件加载期间的新批量操作。插件重载、思源重启或旧版本已执行的操作，不能自动补进撤销栈。

## 建议

- 批量操作前先确认开始、结束、目标标记在同一逻辑范围内
- 移动和复制需要 `批量目标`，删除不需要
- 如果快捷键难记，直接使用顶部栏图标右键菜单
